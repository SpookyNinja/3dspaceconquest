# Asset ledger

Every third-party file shipped in `public/assets/` is listed here with its source, author and licence (see SPEC §8).
Player-facing credits live in [`CREDITS.md`](../CREDITS.md). Machine-readable list of every file: `public/assets/manifest.json`.

Preview everything in a browser: serve `public/` (for example `cd public && python3 -m http.server`) and open
`/asset-preview.html`. Views can be opened directly with `#fleet`, `#planets`, `#ship:0` and so on.

## Ships (`public/assets/models/ships/`)

Source: Quaternius, *Ultimate Spaceships* pack, https://quaternius.com/packs/ultimatespaceships.html, licence CC0 1.0
(`License.txt` in the pack). The author's Google Drive download was rate-limited, so the files were taken from the
unmodified public mirror https://github.com/yolanother/QuaterniusUltimateSpaceships (commit `c005a95`), whose
folder layout and `License.txt` match the original pack.

Each ship has a 2048 px texture atlas in five colours (Blue, Green, Orange, Purple, Red). We bake one colour per GLB:
**blue = player**, **red = enemy**. Other colours can be baked for more factions by adding rows to `build-assets.mjs`.

**Scale and orientation.** Models are centred on the origin. After Babylon's glTF import, ship noses point along **+Z**
and up is +Y. The pack has no dedicated capital ship, so the player battlecruiser is the largest hull (Imperial) scaled
up 4×, which makes it 6 to 9 times longer than a fighter. It is a placeholder until a proper hero model is bought or
commissioned (SPEC §8). Enemy elites and bosses can use `enemy_cruiser.glb` at 1.5 to 3× to stay close to the player's size.

## Pipeline

Source packs are not committed (SPEC §7: only optimized output goes in git). To rebuild:

1. Download the packs above into `assets/source/` (gitignored) using these folder names:
   `quaternius-ultimate-spaceships/`, `kenney-space-kit/`, `kenney-particle-pack/`, `kenney-scifi-sounds/`,
   `solarsystemscope/` (the JPGs), `ambientcg/<AssetId>/` (unzipped 1K-JPG packages).
2. `cd assets/tools && npm install && npm run build` (ships, props, sprites, sounds, textures, `manifest.json`).
3. `python3 assets/tools/gen-planets.py` (needs numpy and Pillow) for the two planet maps.

What the build does: ship atlases go from 2048 px PNG to 512 px JPEG (1024 px for the player), meshes are welded,
deduplicated and centred; OBJ props are converted to GLB. Total size is about 7.7 MB. Meshopt/KTX2 compression
(SPEC §5) is not applied yet because the meshes are tiny; add it when real hero models arrive.

## Adding an asset

1. Check the licence of that specific asset. Prefer CC0 or CC BY; avoid NonCommercial.
2. Add it to the build script (or drop the optimized file in `public/assets/`), then add a row here.
3. If the licence needs attribution, add it to `CREDITS.md` too.
